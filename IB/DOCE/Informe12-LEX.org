* Objetivo
- Implementar un analizador léxico que reconozca números hexadecimales
  del tipo 0x1A3F y muestre su valor
  decimal.

* Procedimientos y Conclusiones
Este programa reconoce números hexadecimales como 0x1A3F y muestra su
valor decimal (Ver Anexo @@latex: \ref{anexo:a1}@@). El mismo constó de su correspondiente ejecución con
=GCC=, y valores a analizar (de entrada) con su correspondiente
salida.  

El patrón =0[xX][0-9a-fA-F]+= exige el prefijo =0x=, y luego al menos un
dígito hexadecimal, en mayúscula o minúscula. En la acción se usó
=yytext + 2= para saltar el prefijo y =strtoull= con base 16 para convertir a un entero.

Igual que en el caso anterior, la regla =PALABRA= va después de la regla
válida. Así, entradas como =0x1AG=, =FF= o =0x= se reportan como error,
porque la regla de error reconoce más caracteres que el patrón
hexadecimal.

* Recomendaciones

La expresión =0[xX][0-9a-fA-F]+= acepta mayúsculas y minúsculas
(=0xff=, =0xFF=, =0XfF=). Se exige al menos un dígito (+) tras =0x=,
esto evita aceptar 0x solo. De igual manera, el uso de la regla =HEXA=
antes de =PALABRA= evita que una cadena válida se rechace.

%{
#include <stdio.h>

%}

%option noyywrap

HEXA      0[xX][0-9a-fA-F]+
PALABRA   [0-9A-Za-z_]+

/* ---------- Reglas ---------- */
%%
{HEXA}      {
                if (yyleng - 2 > 16) {
                    printf("Aviso: '%s' excede los 16 digitos hexadecimales.\n", yytext);
                } else {
                    /* yytext+2 salta el prefijo "0x" */
                    unsigned long long valor = strtoull(yytext + 2, NULL, 16);
                    printf("Hexadecimal %s = %llu en decimal\n", yytext, valor);
                }
            }

{PALABRA}   { printf("ERROR: '%s' no es un hexadecimal valido (use 0x...)\n", yytext); }

[ \t\r\n]+  { /* ignorar espacios y saltos de linea */ }

.           { printf("ERROR: caracter no reconocido '%s'\n", yytext); }
%%

/* ---------- Codigo (main) ---------- */

    yylex();
    return 0;
