* Objetivo
- Implementar un analizador léxico que procese listas de elementos
  separados por comas. Cada elemento puede ser un identificador o un
  número entero. Si encuentra otro tipo de token, se lo reporta como error.

* Procedimiento y Conclusiones
Este analizador procesa listas de identificadores y enteros separados
por comas, y reporta errores.

Primero se definen los tokens: =ID= empieza con letra o guión bajo, y =ENTERO=
son dígitos con signo opcional. También se definió =MALFORMADO=, para
detectar casos como 5x que no son ni identificador, ni número.

Lo más importante es la variable =esperaElem=. Funciona como un pequeño
autómata: si espera un elemento y llega una coma, es error; si espera
una coma y llega un elemento, falta una coma.

Al leer el salto de línea, la función fin_de_lista muestra el resumen
y reinicia el estado. Este control de estructura anticipa el trabajo de Yacc.

* Recomendaciones
Es mejor definir ={MALFORMADO}= para que =5x= no se parta en 5 y
x. Sin esa regla, Lex lo leería como dos tokens válidos sin coma.
={ID}= y ={ENTERO}= no se solapan (uno empieza con letra, el otro con
dígito), así que su orden no afecta.
Esta idea (un pequeño autómata con variables de estado) es lo que Yacc
automatiza con gramáticas. Una lista se escribiría como =lista : elem |
lista ',' elem ;=.

Lex puede manejar estados con start conditions (=%x=), pero para este
nivel las variables en C son más claras.

/* ---------- Declaraciones ---------- */
%{
#include <stdio.h>

int elementos   = 0;   /* elementos validos en la lista actual */
int errores     = 0;   /* errores en la lista actual           */
int esperaElem  = 1;   /* 1 = toca un elemento, 0 = toca coma  */

void elemento(const char *tipo, const char *texto);
void fin_de_lista(void);
%}

%option noyywrap

LETRA     [a-zA-Z_]
DIGITO    [0-9]
ID        {LETRA}({LETRA}|{DIGITO})*
ENTERO    -?{DIGITO}+
MALFORMADO {DIGITO}+{LETRA}({LETRA}|{DIGITO})*

/* ---------- Reglas ---------- */
%%
{MALFORMADO}  {
                  printf("ERROR: token mal formado '%s' (empieza con digito pero no es entero)\n", yytext);
                  errores++;
                  esperaElem = 0;   /* ocupa el lugar de un elemento */
              }

{ID}          { elemento("identificador", yytext); }

{ENTERO}      { elemento("entero", yytext); }

","           {
                  if (esperaElem) {
                      printf("ERROR: coma sin elemento antes\n");
                      errores++;
                  }
                  esperaElem = 1;
              }

[ \t\r]+      { /* ignorar espacios */ }

\n            { fin_de_lista(); }

.             {
                  printf("ERROR: token no valido '%s'\n", yytext);
                  errores++;
              }
%%

/* ---------- Subrutinas del usuario ---------- */
void elemento(const char *tipo, const char *texto)
{
    if (!esperaElem) {
        printf("ERROR: falta una coma antes de '%s'\n", texto);
        errores++;
    } else {
        printf("  Elemento %d: %s (%s)\n", elementos + 1, texto, tipo);
        elementos++;
    }
    esperaElem = 0;
}

void fin_de_lista(void)
{
    if (esperaElem && (elementos > 0 || errores > 0)) {
        printf("ERROR: la lista termina en coma\n");
        errores++;
    }
    if (elementos > 0 || errores > 0) {
        printf("=> Lista con %d elemento(s) valido(s) y %d error(es)\n\n",
               elementos, errores);
    }
    elementos = 0; errores = 0; esperaElem = 1;   /* reiniciar */
}

int main()
{
    yylex();
    return 0;
}
#+end_src
